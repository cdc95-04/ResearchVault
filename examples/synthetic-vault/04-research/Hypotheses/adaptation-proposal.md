# Synthetic adaptation hypothesis draft

For a yet-to-be-specified controlled setting, an adaptation update might improve
prediction after a body change relative to the same model without updates.

This conjecture illustrates the distinction between a hypothesis and a result.
No experiment has run. Equal information access, update budget, evaluation data,
metric, denominator and falsifier would need specification before a Research
Card or lock could be justified. A review could also show this is already known
or that a different explanation is more plausible.

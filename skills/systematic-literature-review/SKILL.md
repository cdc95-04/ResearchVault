# Systematic literature review

Read [review](../../references/review.md). Start from the
[protocol](../../templates/reviewprotocol.md) and
[corpus](../../templates/reviewcorpus.yaml) only when those objects are needed.

Define scope and inclusion/exclusion criteria before screening. Record query
families, sources, seed identities and bounded backward/forward citation rounds.
Preserve every executed query and screening decision with its reason. Track
duplicate identity resolution explicitly.

Search for supporting, competing, contradictory, null and alternative-mechanism
work. A challenge search with no returned papers remains a recorded search, not
proof that no contrary evidence exists. Describe coverage by dimensions and
unsearched areas; paper count is never a stopping proof or completeness score.

Build the Evidence Matrix from source-grounded Notes, with each paper's position,
finding and limitations. Show proposed corpus-freeze metadata before applying a
receipt. A changed protocol or added paper requires a documented revision;
preserve the earlier corpus and its linked Gap's historical evidence.

Deliver the actual search boundary, unresolved screening, conflicting evidence
and justified stopping reason. Pass a coverage-backed Gap candidate to
research-maintainer only if one survives the review; a finding of no defensible
gap is valid. Discovery and acquisition remain separate responsibilities.

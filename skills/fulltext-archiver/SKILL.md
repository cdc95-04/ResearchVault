# Fulltext archiver

Read [evidence](../../references/evidence.md) and the
[Fulltext template](../../templates/fulltext.md). Resolve the parent, attachment
and available source before writing.

Archive original text without paraphrasing, analytical insertions or silent
corrections. Keep extraction method, source identity and content hash with the
record. Store externally produced structured parsing as an optional input only;
do not represent it as a built-in extraction capability.

Reuse an existing artifact only after identity and source integrity agree. A
different extraction for the same attachment is a provenance question, not
permission to overwrite. Show a diff for an authorized update. Report unreadable
pages, extraction gaps and unavailable PDFs honestly; leave verified states unset
until their supporting material has been inspected.

The output is source evidence and its availability report. Hand analysis to
paper-note-writer. Do not synthesize a Note or Knowledge page inside Fulltext.
